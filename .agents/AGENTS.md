# Workspace Rules — FastFoodCash

## Auto Git Push Rule
Har safar biror fayl o'zgarganda yoki yangi vazifa/tuzatish bajarilganda:
1. Tekshiruv (build/test) o'tkaziladi.
2. Avtomatik ravishda `git add .`, `git commit -m "..."` va `git push origin main` bajariladi.
3. Foydalanuvchidan "git push qilaymi" deb so'ralmaydi, o'zi avtomatik push qilinadi.
